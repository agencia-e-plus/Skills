# PageSpeed & Web Vitals Triage

Skill para triagem técnica, diagnóstico e estimativa de horas em chamados de desempenho no Compass / atendimento a partir de links de relatórios do Google PageSpeed Insights.

---

## 🎯 Escopo

- Análise baseada no snapshot exato de auditoria gerado pelo cliente (`pagespeed.web.dev/analysis/...`).
- Zero dependência de chaves de API externas ou variáveis de ambiente.
- Interpretação das métricas de laboratório cruzadas com dados reais de campo (CrUX).
- Delimitação clara entre ajustes técnicos no tema, correção pontual de app fork VTEX IO (só quando o tema não resolve o achado) e impactos de scripts de terceiros/marketing.
- Cotação calibrada com a tabela de On Going da agência.

---

## 📋 Como Chamar no Cursor

Inicie uma conversa (`Ctrl + L`) e forneça o link da análise e o contexto do chamado:

```text
Por favor, realize a triagem técnica do chamado de performance da loja [Nome da Loja].
Link do relatório: [https://pagespeed.web.dev/analysis/](https://pagespeed.web.dev/analysis/)...
Contexto do chamado: [Descrição ou relato do cliente no chamado]
Repositório (opcional): deco-sites/[repo] (Deco.cx) ou agencia-e-plus/[repo] (demais plataformas)
```
